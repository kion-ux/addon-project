# 進撃の巨人アドオン — 設計メモ（実装の基準）

名前空間 `aot`。パックは `packs/aot_BP` / `packs/aot_RP`。生成は `tools/aot/`、
ビルドは `./build_aot.sh`。スクリプト API は `@minecraft/server 1.13.0` と
`@minecraft/server-ui 1.2.0` の安定版のみ（ベータ API 不要）。

## 1. 中心の遊び

1. 立体機動装置（脚スロット）を着て、刃（超硬質スチール）を持つ
2. 右クリック長押しでアンカーを撃ち込み、ワイヤーを巻き取って飛ぶ（離すと切り離して慣性で飛ぶ）
3. 巨人は **うなじ** 以外を斬っても蒸気を上げて再生する。うなじを勢いよく削ぐと倒れて蒸発する
4. 刃は消耗して折れる → 替え刃で自動交換。ガスも尽きる → ガスボンベで補給

## 2. 操作

| 操作 | 条件 | 効果 |
|---|---|---|
| 右クリック長押し | 立体機動装置＋刃 | アンカー射出（視線の先 45m まで）。押している間ワイヤーを巻き取る |
| 右クリックを離す | 同上 | アンカーを外す（勢いは残る） |
| 空中でジャンプ | 同上 | ガス噴射（視線方向へ加速） |
| 空中でスニーク | 同上 | 回転斬り（周囲を斬る。うなじが範囲内なら削ぐ） |
| 攻撃 | 刃 | 斬撃。うなじに当たれば討伐（遅いと「浅い」） |
| 巨人に刺したアンカーを巻き取ってうなじの脇を抜ける | 同上 | 自動でうなじを削ぐ |
| 掴まれた時にスニーク | 刃＋ガス10以上 | 指を斬って脱出 |
| 雷槍を右クリック | — | 雷槍を撃つ。刺さって 1.2 秒後に爆発 |
| ガスボンベを右クリック | — | ガス補給 |
| 手帳を右クリック | — | 状態・操作説明・巨人図鑑・設定・装備支給 |

着地: 立体機動装置を着てガスが残っていれば、落下の直前にガスを噴いて落下ダメージを消す。

## 3. うなじの判定（スクリプト）

* うなじ位置 N = 巨人の足元 + 上 × 首の高さ × 倍率 − 前 × 首の奥行き（膝をついていると下がる）
* プレイヤーの視線の半直線と N の最短距離 ≤ うなじ半径 + 0.6、かつ 後ろか上から（前からは不可）
* 速さ ≥ 0.3 ブロック/tick、または 25 tick 以内にワイヤーを使った、または回転斬り → 討伐
  それ以外は「浅い」: 最大体力の 40% を与え、5 秒再生しない
* 足首（巨人の高さの 25% 以下）を斬ると 30% で「腱を削いだ」: 6 秒膝をつく（うなじが下がる）
* 目（頭の前）を斬ると「目を潰した」: 6 秒標的を失う

## 4. 巨人

| ID | 級 | 全高 | 体力 | 当たり判定（衝突 / 被弾） |
|---|---|---|---|---|
| `aot:titan_small` | 4m級 | 4m | 50 | 1.0×3.2 / 1.4×4.0 |
| `aot:titan_medium` | 7m級 | 7m | 110 | 1.6×3.8 / 2.2×7.0 |
| `aot:titan_large` | 13m級 | 13m | 220 | 2.4×4.8 / 3.4×13 |
| `aot:titan_abnormal` | 奇行種 10m | 10m | 160 | 2.0×4.2 / 2.8×10 |

* 見た目: 体型 4 種（細長い手足 / 肥満 / 筋肉質 / 大頭）× 顔と肌 3 種 = 12 通り。
  ジオメトリは全高 3m で作り、クライアント側の `scripts.scale` で各級へ拡大する
* 体へのダメージは 25%（爆発・炎は 40〜50%）。最後に被弾してから 3 秒で毎秒 3% ずつ再生し、傷から蒸気
* 掴み（7m 級以上・奇行種）: 近接攻撃が当たると 35% で掴む → 1.5 秒後に口へ → 2.5 秒で噛む
* 払い: 上半身の前に浮いているプレイヤーを腕で払う
* 夜は動きが鈍り座り込む（日光が無いと動けない）。攻撃されると起きる
* 奇行種: 突然の跳躍・全力疾走
* 討伐: 前のめりに倒れ、4 秒蒸気を上げて消える。経験値を落とす。素材は落とさない
* 葉・草・ガラスは歩くと壊す
* 状態は entity property `aot:state`（idle/grab/eat/kneel/sleep/dying/leap/swat/blind）で RP に渡す

## 5. 調査兵団（味方 NPC）

エレン / ミカサ / アルミン / リヴァイ / ハンジ / エルヴィン / ジャン / サシャ / コニー / 調査兵。
巨人を見つけるとスクリプトで立体機動の攻撃を仕掛ける（アンカー → 飛ぶ → うなじ → 離脱）。
成功率はキャラごと（リヴァイ 98% など）。パン（サシャは蒸かし芋＝ベイクドポテト）を渡すと仲間になって付いてくる。

## 6. アイテム

立体機動装置（脚）/ 調査兵団のジャケット（胴・自由の翼のマント付き）/ 兵団ブーツ（足）/
刃（両手に一振りずつ描く）/ 替え刃 / ガスボンベ / 雷槍 / 信煙弾（緑・赤・黒）/
超硬質スチール（素材）/ 調査兵団の手帳

## 7. 演出

ワイヤー（1 本を数個の細長いパーティクルで描く）、ガスの噴射、蒸気、血しぶき、斬撃の弧、
雷槍の火花と爆発、信煙弾の煙柱、巨人の足音と画面揺れ、効果音はすべて合成。
プレイヤーの全身モーション（飛行姿勢・回転斬り・うなじ斬り・掴まれ）は playanimation。
