# アストロ・ナノギア パーティクル一覧（PARTICLES.md）

`tools/astro/gen_astro_particles.py` が生成する。**このファイルは手で直さない**（生成スクリプトを直して作り直す）。
惑星の技の演出はこの表だけを見て書けるようにしてある。見た目の確認は `ASTRO_PREVIEW=1 python3 tools/astro/gen_astro_particles.py` → `build_preview/astro/particles_*.png`（JSON をそのまま動かした簡易シミュレーション。`ASTRO_PREVIEW_ONLY=beam,bolt` で一部だけ）。

## 使い方

```js
const m = new MolangVariableMap();
m.setFloat("variable.cr", 0.47); m.setFloat("variable.cg", 0.94); m.setFloat("variable.cb", 1.0);
m.setFloat("variable.size", 2.0);
dim.spawnParticle("astro:ring_flat", pos, m);   // fx.js の P() がこれを包む
```

* 変数は全て任意。渡さなければ各粒の表の既定値になる（変数無しでも見栄えがする既定にしてある）。変数名は必ず `variable.` を付けて setFloat する（`v.` ではない）。
* **色** `cr cg cb` は 0..1。スプライトは白で描いてあり、`minecraft:particle_appearance_tinting` でこの色に染める。「白→色」と書いた粒は生まれた瞬間だけ白く光ってから色に落ちる。
* **size** は倍率。各粒の「size 1 の大きさ」の欄が基準（m）。
* **life** は粒の寿命（秒）。連続で出す粒（vortex・nano_stream）は欄に書いた意味になる。
* **vx vy vz** の意味は粒ごとに違う（**向き**・**終点のずれ m**・**速度 m/s**・**面の法線**）。向きとして使う粒は内部で正規化するので長さは関係無い（長さは `len` で渡す）。3 つとも 0 か未指定なら既定の向き/点になる。1 つだけ渡すと残りは 0 として扱う。
* 向き・ずれは **ワールド座標** で渡す（`p.getViewDirection()`、`B − A` など）。
* 「水平」の粒（ring_flat・shock_flat・circle・hex_circle・emblem・slash_flat・warning）は地面と平行（emitter_transform_xz。スクリプトから出すエミッタは回転しないので常にワールドの水平面）。地面に置く時は y を +0.05〜0.1 上げると埋まらない。
* 「加算」は光る（暗い所ほど目立つ。黒は描けない）。「半透明」は色がそのまま乗る（煙・雲・岩・警告・虚空）。
* spawnParticle 1 回 = 全員へのパケット 1 つ。輪や線は `ring_n`・`line_n` で 1 回にまとめる。粒数（fx.js の予算は 1 tick 260 粒）は各粒の **粒数** の欄。

### 変数の早見表（共通の意味。粒ごとの意味は各表）

| 変数 | 意味 |
|---|---|
| `cr` | 色の赤 (0..1) |

| `size` | 大きさの倍率（各粒の基準の大きさに掛ける） |
| `life` | 粒の寿命 (秒) |

| `count` | 粒の数 |
| `speed` | 初速 (m/s) |
| `spread` | 散らばりの半径 (m) |

| `vy` | 向き Y |
| `vz` | 向き Z |
| `var` | スプライトの種類 |
| `height` | 高さ (m) |
| `spin` | 回転の速さ (度/秒) |
| `rate` | 放出レート (粒/秒) |
| `grav` | 重力加速度 (m/s²、下向きは負) |
| `len` | 長さ (m) |

## 組み合わせの例

* **命中**: `impact`（size 1）+ `spark`（count 6、向き = 攻撃の向き）+ `ring`（size 0.6）
* **重い命中・叩きつけ**: `impact`（size 2）+ `shock_flat` + `dust` + `debris`
* **斬撃**: `slash`（rot で弧の向き、var 0/1 で左右の振り）+ `spark`。大技は `slash_big`、回転斬りは `slash_flat`
* **光線**: `circle_v`（発射口。向き = 視線）+ `beam`（毎 tick 出すか life を伸ばす）+ `flare`（撃った瞬間）+ `glow`/`impact`（着弾点）
* **落雷**: `warning`（予告）→ `bolt`（地面の点から len 12）+ `impact` + `shock_flat` + `arc`
* **連鎖放電**: A から B へ `bolt`（vx,vy,vz = B − A、len = 距離）+ B に `arc`
* **溜め**: `converge` + `orbit` + 芯に `glow`
* **変身**: 足元に `circle` + `scan` + コアから各部位へ `nano_stream`（vx,vy,vz = 部位 − コア）+ 締めに `emblem`（var = 惑星番号）+ `ring_n`
* **範囲の縁**: `ring_n`（spread = 半径、1 回で輪）か `ring_flat`（広がる輪）
* **軌跡・射線**: `line_n`（1 回で線）か `trail` を並べる
* **ブラックホール**: `black_hole` + 同じ点・同じ色で `lens`（size × 0.8、加算の光）+ `converge`
* **隕石**: `warning` → `meteor`（毎 tick 位置を変えて出すか speed で飛ばす）→ `impact` + `shock_flat` + `debris` + `smoke`
* **水**: `wave`（向き = 進む向き）+ `splash` + `droplet` + `bubble`
* **凍結**: `ice` + `shard` + `hex`（count と spread で氷の殻）

## 個別

### `astro:glow`

* 見た目: 丸い発光の玉（白い芯 + 柔らかい光）。生まれた瞬間は白く、すぐ色に落ちる
* 材質: 加算（光る） / 白→色 / 粒数: count（既定 1）
* size 1 の大きさ: 直径 0.5 m（寿命の間に半分まで縮む）
* 用途: 命中点・溜めの芯・軌跡の点打ち
* 目安: size 0.6〜2 / life 0.3〜0.6

| 変数 | 既定 | 意味 |
|---|---|---|
| `cr` `cg` `cb` | (0.47, 0.94, 1.0) | 色 (0..1) |
| `size` | 1.0 | 大きさの倍率（各粒の基準の大きさに掛ける） |
| `life` | 0.4 | 粒の寿命 (秒) |
| `vx` `vy` `vz` | (0, 0, 0) | 飛ぶ向き（speed > 0 の時。未指定は上） |
| `spread` | 0.0 | 散らばりの半径 (m) |
| `count` | 1.0 | 粒の数 |
| `speed` | 0.0 | 初速 (m/s) |

## 注意（作業者向け）

* `lookat_direction` の粒（beam・bolt・thrust・meteor・spark・speedline・wind・droplet・converge・orbit・vortex）はスプライトの**横（size[0]）が向きに沿う**。向きの軸まわりにカメラへ回るので帯は常に見える（真正面・真後ろから見ると点になる）。
* `circle_v`・`wave` は `direction_z`（面が向きを向く）なので、真横から見ると薄くなる。
* `black_hole` は半透明（blend）の一枚絵で、核は黒のまま（染まらない）。光らせたい時は同じ点に `lens`（加算）を同じ色で重ねる（DESIGN の「blend + add の二層」はこの二つで作る）。
* 寿命の長い陣（circle 系・emblem・black_hole・cloud・aurora）は現れる/消える速さが秒で決まっているので、life を何秒にしても点き方は同じ。
* `nano_stream` は放出に `count / rate` 秒かかる。最後の粒が着くのは `life + count / rate` 秒後。
* `vortex` の `life` は放出時間。同時最大 160 粒、nano_stream は 120 粒で打ち切る。
* `debris` だけ地形と衝突する（地面で跳ねる）。
* `slash` 系の `rot` は弧の向き（回す向きの正負はゲーム内で確かめること）。右振りと左振りは `var` 0/1 で選ぶ（回転では鏡像にならない）。
* `emblem` の `var`: 0 mercury / 1 venus / 2 earth / 3 mars / 4 jupiter / 5 saturn / 6 uranus / 7 neptune / 8 sol / 9 汎用（既定）。色を渡さなければその惑星の発光色。
* 加算の粒は RGB とアルファの両方に消え方を掛けている（加算の材質がアルファを見るか確かめられないため）。
