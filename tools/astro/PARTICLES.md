# アストロ・ナノギア パーティクル一覧（PARTICLES.md）

`tools/astro/gen_astro_particles.py` が生成する。**このファイルは手で直さない**（生成スクリプトを直して作り直す）。
惑星の技の演出はこの表だけを見て書けるようにしてある。

## 使い方

```js
const m = new MolangVariableMap();
m.setFloat("variable.cr", 0.47); m.setFloat("variable.cg", 0.94); m.setFloat("variable.cb", 1.0);
m.setFloat("variable.size", 2.0);
dim.spawnParticle("astro:ring_flat", pos, m);   // fx.js の P() がこれを包む
```

* 変数は全て任意。渡さなければ下の表の既定値になる（変数無しでも見栄えがする既定にしてある）。
  変数名は必ず `variable.` を付けて setFloat する（`v.` ではない）。
* **色** `cr cg cb` は 0..1。スプライトは白で描いてあり、`particle_appearance_tinting` でこの色に染める。
  多くの発光は生まれた瞬間だけ白く光ってから色に落ちる（表の「白→色」）。
* **size** は倍率。各粒の「基準の大きさ」は個別の欄に書いた m（size 1 の時）。
* **life** は粒の寿命（秒）。連続で出す粒（vortex・nano_stream）は欄に書いた意味になる。
* **vx vy vz** の意味は粒ごとに違う（**向き**か**終点のずれ m**か**速度 m/s**か）。向きとして使う粒は内部で正規化するので長さは関係無い（長さは `len` で渡す）。3 つとも 0 か未指定なら既定の向き/点になる。1 つだけ渡すと残りは 0 として扱う。
* 向きのある粒（beam・bolt・thrust・meteor・circle_v・wave）は **ワールド座標の向き** をそのまま渡す（`p.getViewDirection()` や `B − A`）。
* 「水平」の粒（ring_flat・shock_flat・circle・hex_circle・emblem・slash_flat・warning）は地面と平行（emitter_transform_xz。スクリプトから出すエミッタは回転しないので常にワールドの水平面）。地面に置く時は y を +0.05〜0.1 上げると埋まらない。
* 「加算」は光る（暗い所ほど目立つ。黒は描けない）。「半透明」は色がそのまま乗る（煙・雲・岩・警告）。
* 粒数の目安（fx.js の予算は 1 tick 260 粒）は各欄の **粒数**。

### 変数の早見表（共通の意味）

| 変数 | 意味 |
|---|---|
| `cr` | 色の赤 (0..1) |
| `cg` | 色の緑 (0..1) |
| `cb` | 色の青 (0..1) |
| `size` | 大きさの倍率（各粒の基準の大きさに掛ける） |
| `life` | 粒の寿命 (秒) |
| `rot` | 面内の回転 (度) |
| `count` | 粒の数 |
| `speed` | 初速 (m/s) |
| `spread` | 散らばりの半径 (m) |
| `vx` | 向き X |
| `vy` | 向き Y |
| `vz` | 向き Z |
| `var` | スプライトの種類 |
| `height` | 高さ (m) |
| `spin` | 回転の速さ (度/秒) |
| `rate` | 放出レート (粒/秒) |
| `grav` | 重力加速度 (m/s²、下向きは負) |
| `len` | 長さ (m) |

* 見た目: 丸い発光の玉（白い芯 + 柔らかい光）。生まれた瞬間は白く、すぐ色に落ちる
* 材質: 加算（光る） / 粒数: count（既定 1）
* 用途: 命中点・溜めの芯・軌跡の点打ち
* 目安: size 0.6〜2 / life 0.3〜0.6

| `vx` | 0.0 | 飛ぶ向き（speed > 0 の時。未指定は上） |
| `vy` | 0.0 | 飛ぶ向き（speed > 0 の時。未指定は上） |
| `vz` | 0.0 | 飛ぶ向き（speed > 0 の時。未指定は上） |

## 注意（作業者向け）

* `lookat_direction` の粒（beam・bolt・thrust・spark・speedline・wind・droplet・converge・orbit・vortex）はスプライトの**横（size[0]）が向きに沿う**。向きの軸まわりにカメラへ回るので帯は常に見える。
* `circle_v`・`wave` は `direction_z`（面が向きを向く）なので、真横から見ると薄くなる。
* `black_hole` は半透明（blend）の一枚絵で、核は黒のまま（染まらない）。光らせたい時は同じ点に`lens`（加算）を同じ色で重ねる（DESIGN の「blend + add の二層」はこの二つで作る）。
* 寿命の長い陣（circle 系・emblem・black_hole・cloud・aurora）は現れる/消える速さが秒で決まっているので、life を何秒にしても点き方は同じ。
* `nano_stream` は放出に `count / rate` 秒かかる。最後の粒が着くのは `life + count / rate` 秒後。
* `vortex` の `life` は放出時間。同時最大 160 粒、nano_stream は 120 粒で打ち切る。
* `debris` だけ地形と衝突する（地面で跳ねる）。
* 色の既定値は粒ごとに違う（下の各表）。`emblem` は v.var の惑星の発光色が既定。
