# 持ち方の規則と、その根拠

`hd_space.py` の定数と回転の規則は、Mojang の公式サンプル
（[bedrock-samples](https://github.com/Mojang/bedrock-samples) の `resource_pack/`）の実データから決めた。
ここにはその根拠と、規則を使って武器の持ち方・全身モーションを決める仕組みをまとめる。

## 1. 回転の向き

ボーン・キューブの `rotation: [rx, ry, rz]` は、モデル空間の右手系で

```
R = Rz(-rz) · Ry(+ry) · Rx(-rx)        （X → Y → Z の順に掛かる）
```

| 確かめた所 | 値 | 読み取れること |
|---|---|---|
| `animation.humanoid.bow_and_arrow`（弓を引く腕） | 右腕 rx = `q.target_x_rotation - 90` | 負の rx で腕が前へ上がる |
| `animation.player.first_person.base_pose`（一人称の右腕） | rotation `(95, -45, 115)`、position `(13.5, -10, 12)` | 一人称のカメラは目 `(0, 26, 0)` から +Z を見ていて、画面は X が鏡映 |
| `animation.player.holding` | `rightarm.rotation[0] = -this * 0.5 - 18.0` | 何かを持つと右腕に -18° が足され、それまでの振り（歩き）が半分になる |

`hd_scene.py` はこの規則でプレイヤーの骨格を組んで描く。正の ry は右（-X 側）を向き、
正の rz は右腕を外へ開く（左腕は負の rz で外）。

## 2. アタッチャブルの付き方

`binding: q.item_slot_to_bone_name(c.item_slot)` で手のボーンに付けたボーンは、
対象ボーンの pivot（右手 `rightItem` は `[-6, 15, 1]`）にずれを持ち、右手で `(-6, -9, -1)`、左手で `(6, -9, -1)`。
拳の中心（腕を下ろした時 `(-6, 13.2, 0)`）に握りの点を置くには、ボーンを `(0, 22.2, 1)` 動かす（`GRIP_POS`）。

バニラの盾（`animation.shield.wield_third_person`: position `[-0.4, 9.0, 9.3]`、rotation `[-90, 0, 90]`、
scale `[1, -1, -1]`）・トライデント・望遠鏡のアタッチャブルをこの規則で `hd_scene.py` に描き直し、
見慣れた持ち方（盾は前腕の外側で面が外向き、トライデントは拳から前上）になることで確かめた。
**実機（Minecraft）での確認はまだ**なので、ずれていたらここの定数を直せば全武器の持ち方が一緒に直る。

## 3. プレイヤーの公開変数

`entity/player.entity.json` は `variable.attack_time` を `public` にしている。
アタッチャブルからは `c.owning_entity->v.attack_time` で攻撃の振り（0→1）を読める（武器自身の手首の返しに使う）。

## 4. 持ち方の決め方（`hd_holds.py`）

武器は「握り = 原点、刃 = -Z、刃の幅 = ±Y」で作ってある。武器ごとに、三人称で

* 刃を世界のどちらへ向けるか（`frame(fwd, up)`）
* どこを握るか（握りの点。両手武器は右手と左手の 2 点）
* その時の腕の角度

を決め、`item_rotation` / `item_position` で逆算してアタッチャブルの rotation / position を出す。

**両手武器**: 腕は肘の無い棒（肩から拳の中心まで 8.86）なので、両方の拳で一本の柄を握れるのは、
両肩からの距離が腕の長さになる「体の正面の弧」（中心 `(0, 22, 0)`、半径 ≈7.3、x = 0 の面）の近くだけ。
`two_hand_place()` は右腕の向きを探して、左の拳が二つ目の握りに届き、武器（柄頭・石突き・鍔）が
体に入らない所を選ぶ。

**手首は固定**: アタッチャブルは腕に付いて一緒に回るだけなので、構えの「前腕と武器の角度」が
すべての振りに残る。大剣を水平に近い中段（前腕と約 30°）、斧を斧頭を前下に置く下段にしているのは、
振り下ろしの終わりで刃が前〜前下を向くようにするため（前腕と 75° 以上だと、振り下ろしても刃が上を向いて終わる）。

## 5. 全身モーションを武器ごとに解く（`hd_pose.py`）

モーションは腕の角度（両手武器は「手の高さ」と「刃の向き」）で書き、武器ごとに

1. はみ出さない三次補間（Fritsch–Carlson）で 0.05 秒ごとのキーに刻む
2. 各キーで、武器を持つ腕の角度を座標降下で探す。コスト:
   * 武器の表面の点が頭・胴・脚・空いた腕の箱（帽子 0.5・上着 0.25 の厚みを含む）に入り込む深さ
   * 両手武器: 左の拳と柄の二つ目の握りの距離（左腕は構えの姿勢から最小の回転で握りへ向けるので、
     ねじれが通ってきた道に依らない）
   * 書いた腕の向き・刃の向きからのずれ、前のキーからの補正の変化（キーの間で腕が跳ばない）
3. 統合版と同じ catmullrom で 0.02 秒ごとに補間して調べ、入り込む所にキーを足して解き直す

`check_hd_clip.py` が書き出した全モーションを同じ規則で調べ、入り込み 0.6px 超、
または両手武器の左手が柄から 2px 以上離れるコマがあればビルドを止める。
解いた結果は入力（持ち方・キー・モデル・解き方のコード）のハッシュごとに `.cache/poses.json` に残す。
