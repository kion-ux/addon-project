# 怪獣8号 アドオン (Kaiju No.8 Add-on)

Minecraft **統合版 (Bedrock Edition)** 用の非公式ファンメイド・アドオンです。
アニメ『怪獣8号』の世界 —— 日本防衛隊、識別怪獣、解放戦力、原作の技、そして
「人間のまま怪獣になった男」の変身 —— をゲーム内に再現します。

- 対応バージョン: **Minecraft Bedrock 1.21.30 以降**
- 使用API: `@minecraft/server 1.13.0` / `@minecraft/server-ui 1.2.0`
- 言語: 日本語 / English（ゲームの言語設定に追従）

---

## 導入方法

1. `dist/KaijuNo8_v1.0.0.mcaddon` をダウンロードする
2. ファイルをタップ / ダブルクリックして Minecraft にインポートする
3. ワールド設定で **ビヘイビアーパック** と **リソースパック** の両方を有効化する
4. ワールド設定の **「ベータAPI」を ON** にする（スクリプト機能に必要）

---

## 操作（これだけ覚えれば戦える）

| 操作 | 効果 |
|---|---|
| 武器を持って **スニーク** | 技を**切り返す**（技ホイールが画面下に出る） |
| 武器を持って **ダッシュ＋スニーク** | 技を**逆順に**切り返す |
| 武器を持って **右クリック** | 選択中の技を発動（保持している間は技の構えモーション） |
| ナンバーズ装備中に **地上でスニーク＋ジャンプ** | ナンバーズ固有能力を発動 |
| 怪獣探知機を右クリック | 周囲の怪獣を索敵 |
| 怪獣探知機をスニーク＋右クリック | 討伐隊端末（解放戦力・技一覧・**ナンバーズ能力**・討伐記録） |
| 「怪獣8号の力」を右クリック | 変身 / 変身中は技が出る |
| 変身中にスニーク＋右クリック | 変身解除 |
| 空中でジャンプ | 空中機動（変身中、または戦闘服＋解放戦力25%以上） |

### 武器のアニメーション

武器は全て3Dモデルで手に持ちます（頭スロットではなく `item_slot_to_bone_name`
バインドで正しく手に付きます）。

* **表裏の二振り** — 攻撃するたび袈裟斬りと逆袈裟が交互に出ます。刀は速い斬り抜け、
  斧と銃剣は担ぎ上げてから落とす溜めの長い大振り、銃は反動、8号の核は引き絞ってからの突き。
* **技モーション** — 右クリックを保持している間、深い溜め → 撓め → 解放 → 残心
  という専用の長いモーションに切り替わります（銃は構え直し→初弾→追撃の三拍）。
* **可動部** — 拳銃はスライドが後退し、火砲は砲身が反動で下がり、バズーカは後方
  噴出口が開き、銃剣は刺突のあとに内蔵銃身が動作し、大戦斧は前縁の放電が膨らみます。
* **構え** — スニーク中は呼吸ぶんだけ揺れる構えに入ります。

技には固有のアニメーション、専用パーティクル（斬撃線・放電・砲口炎・焼灼・衝撃波
など全52種）、効果音、カメラシェイクが付きます。

## システム

### 要塞度 (Fortitude)
怪獣を殴ると **名称・要塞度・残存戦力** がアクションバーに出ます。
余獣は個別に測定されないので `--` 表示です。要塞度6.0以上が本獣級、8.0以上が
大怪獣級、9.0以上が識別種。

### 解放戦力 (Combat Power Release)
討伐隊端末から **1%〜100%** で設定します。原作どおり**オーラは出さず、数値のみ**で
表示され、数値帯によって色が変わります（10-29%青／30-59%緑／60-89%黄／90%以上橙）。

- 解放戦力が高いほど威力と技の回転が上がる
- **戦闘服を一式着ていないと 15% までしか身体が耐えられない**
- 30% を超えると身体に負荷がかかり、体力・満腹度を削る
- 戦闘服一式＋高い解放戦力で移動速度・跳躍力・空中機動が解禁される

### 変身 — 怪獣8号
1. 小型怪獣を**飲み込む**（右クリック長押し）と「怪獣8号の力」を得る
2. 「怪獣8号の力」を右クリックすると **変身**（青緑の閃光と黒煙、画面が揺れる）
3. 変身中は攻撃力・移動速度・防御・跳躍・再生が大幅に強化され、専用の技が使える
4. 高所から落ちると**着地衝撃**で地面が砕け、周囲にダメージが入る
5. 画面下部の **怪獣化ゲージ** が尽きると強制解除され、反動で衰弱する
6. **変身中は日本防衛隊の隊員から怪獣として攻撃される** —— 正体は隠し通せ

変身時に着ていた戦闘服は自動的にしまわれ、変身解除時に着せ直されます。

### 討伐数と階級
`訓練生 → 一般隊員 → 上級隊員 → 副隊長 → 隊長 → 長官`。
討伐数はスコアボード `kaiju8_kills` にも記録されます。

### 怪獣災害
一定間隔でランダムに **怪獣災害警報** が発生し、余獣の群れと本獣が出現します。
討伐数が増えるほど規模が大きくなります。討伐隊端末から ON / OFF できます。

## 開発者向け

モデル・テクスチャ・アニメーション・パーティクル・エンティティ定義・言語ファイルは
すべて `tools/` の Python スクリプトから**生成**されます。`packs/` 配下の生成物を
直接編集せず、生成スクリプトを編集して再ビルドしてください。

```bash
./build.sh                      # 生成 → 検証 → dist/ に .mcaddon / .mcpack を出力
python3 tools/validate.py       # 参照切れ（ジオメトリ・テクスチャ・技・パーティクル等）の検査
python3 tools/check_scripts.py  # スクリプトをスタブ環境で実際にロードして検証
python3 tools/preview.py kafka mina kaiju_no8   # モデルをPNGにレンダリングして確認
```

| パス | 役割 |
|---|---|
| `tools/mcmodel.py` | ジオメトリビルダー。面ごとUV＋テクセルスケールで小さな部位も高解像度に |
| `tools/rig.py` | 身長と等身から骨格を導くリグ。人型・怪獣パーツ・四足獣 |
| `tools/mctexture.py` | UV矩形に沿って描くプロシージャルペインタ（アニメ顔・装甲・発光） |
| `tools/palettes.py` | 全キャラ・全怪獣の配色（調査した原作準拠の hex） |
| `tools/gen_weapons.py` | 武器の3Dモデル。アタッチャブルとNPCの手の両方に同じ形状を使う |
| `tools/gen_entities.py` | 全エンティティのモデルとテクスチャ |
| `tools/gen_anim.py` | 117本のアニメーションと9本のコントローラ |
| `tools/gen_particles.py` | 52種のパーティクルとスプライトアトラス |
| `tools/preview.py` | .geo.json を実際に描画する簡易ソフトレンダラ（Minecraft なしで見た目を検証） |
| `packs/kaiju8_BP/scripts/` | ゲームロジック（技・変身・解放戦力・要塞度・機動・怪獣災害） |

## 原作再現の精度について（重要）

デザイン仕様は本プロジェクトで実施した調査に基づいていますが、**一次資料
（単行本のキャラプロフィール頁、公式サイト、設定資料集、アニメのフレーム）を
直接確認できたものは一つもありません。** 調査は検索結果の要約が情報源で、
「確度が高い」とは「複数の独立したファンwikiが一致している」という意味です。

そのうえで、本アドオンが**解釈で確定させた**主な点：

- **色コードはすべて解釈です。** 公式のhex値は存在せず、「黒」「青緑」「露出した骨」
  といった散文記述からの翻訳です。戦闘服の装甲が「銀」か「白」かも一次確認が
  取れていません（影で銀・光で白に見える中間色で妥協）。
- **等身（頭身）は公表されていません。** 全キャラの等身は作画からの目視推定です。
  身長は公式プロフィールの値を使っています。
- **エンブレム・部隊章の図案は、どの資料にも記載がありません。** 存在と配置しか
  分からないため、本アドオンの図案は完全に独自の暫定デザインです。
- **本獣の全高を 30m → 5.2m に縮小しています。** 原作規格のままでは Bedrock の
  当たり判定と経路探索が破綻するためのゲーム的な妥協です。
- 技名は原作にあるものだけを ✅ とし、原作に存在しない技は捏造せず ⚠️ として
  独自命名であることを明示しています（保科流抜討術4〜6式、隊式格闘術の個別技名などは
  原作に存在しないため**実装していません**）。
- 怪獣9号の要塞度は実測値 8.5 のみ採用し、進化後の数値は出しません。
- 髪・瞳の色は原作とアニメで異なるものがあり（保科の目、鳴海の目、神楽木の髪など）、
  すべて**アニメ版**に統一しています。
- **亜白ミナのバイザーは、原作では目元を覆いますが、本アドオンでは眉の上に薄く掛かる
  位置にしています。** キャラの識別性（瞳の色が見えること）を優先した解釈です。

**未検証事項:** この環境では Minecraft を起動できないため、**インゲームでの動作確認は
未実施です。** 特に、武器の振りモーションは `variable.attack_time` を参照しており、
この変数がアタッチャブル側から読めるかどうかは実機でしか確認できません（読めない場合
でも武器は正しく手に持たれ、構えモーションは動きます）。 モデルは同梱のソフトレンダラ（`tools/preview.py`）で目視確認済み、
参照整合性は `tools/validate.py` で全件検査済みですが、アタッチャブルの手元位置、
技のヒット範囲の体感、パーティクルの見え方は実機での調整が必要です。
