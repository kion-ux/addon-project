# 怪獣8号 アドオン (Kaiju No.8 Add-on)

Minecraft **統合版 (Bedrock Edition)** 用の非公式ファンメイド・アドオンです。
アニメ『怪獣8号』の世界 —— 日本防衛隊、識別怪獣、解放戦力、そして「人間のまま怪獣になった男」
の変身 —— をゲーム内に再現します。

- 対応バージョン: **Minecraft Bedrock 1.21.30 以降**
- 使用API: `@minecraft/server 1.13.0` / `@minecraft/server-ui 1.2.0`（実験機能のトグルは不要）
- 言語: 日本語 / English（ゲームの言語設定に追従）

---

## 導入方法

1. `dist/KaijuNo8_v1.0.0.mcaddon` をダウンロードする
2. ファイルをタップ / ダブルクリックして Minecraft にインポートする
3. ワールド設定で **ビヘイビアーパック** と **リソースパック** の両方を有効化する
4. ワールド設定の **「ベータAPI」を ON** にする（スクリプト機能に必要）

> ビヘイビアーパックを有効にすると、リソースパックは自動的に依存関係として要求されます。

## システム

### 要塞度 (Fortitude)
怪獣を殴ると、防衛隊の識別コードと同じ形式で **名称・要塞度・残存戦力** が
アクションバーに表示されます。識別怪獣は赤で警告表示されます。

### 解放戦力 (Combat Power Release)
討伐隊端末（怪獣探知機をスニーク使用）から **1%〜100%** で設定します。

- 解放戦力が高いほど武器の威力と技の回転が上がる
- **戦闘服を一式着ていないと 15% までしか身体が耐えられない**
- 30% を超えると身体に負荷がかかり、体力・満腹度を削る

### 変身 — 怪獣8号
1. 小型怪獣を**飲み込む**（右クリック長押し）と「怪獣8号の力」を得る
2. 「怪獣8号の力」を右クリックすると **変身 / 解除**
3. 変身中は攻撃力・移動速度・防御・跳躍・再生が大幅に強化される
4. 画面下部の **怪獣化ゲージ** が尽きると強制的に解除され、反動で衰弱する
5. **変身中は日本防衛隊の隊員から怪獣として攻撃される** —— 正体は隠し通せ

変身時に着ていた戦闘服は自動的にしまわれ、変身解除時に着せ直されます。

### 討伐数と階級
怪獣を倒すたびに討伐数が加算され、階級が上がります。

`訓練生 → 一般隊員 → 上級隊員 → 副隊長 → 隊長 → 長官`

討伐数はスコアボード `kaiju8_kills` にも記録されます。

### 怪獣災害
一定間隔でランダムに **怪獣災害警報** が発生し、プレイヤーの近くに余獣の群れと
本獣が出現します。討伐数が増えるほど規模が大きくなります。
討伐隊端末から ON / OFF を切り替えられます。

## コマンド

```
/scriptevent kaiju8:transform     変身 / 解除
/scriptevent kaiju8:power         怪獣8号の力を強制的に付与
/scriptevent kaiju8:terminal      討伐隊端末を開く
/scriptevent kaiju8:alert         怪獣災害を即時発生させる
/scriptevent kaiju8:alerts_on     怪獣災害を有効化
/scriptevent kaiju8:alerts_off    怪獣災害を無効化
/scriptevent kaiju8:reset         自分の討伐記録・力を初期化
```

## 開発者向け

モデル・テクスチャ・エンティティ定義・言語ファイルはすべて `tools/` の
Python スクリプトから**生成**されます。`packs/` 配下の生成物を直接編集するのではなく、
生成スクリプトを編集して再ビルドしてください。

```bash
./build.sh          # 全アセット生成 → 検証 → dist/ に .mcaddon / .mcpack を出力
python3 tools/validate.py       # 参照切れ（ジオメトリ・テクスチャ・ルート等）の検査
python3 tools/check_scripts.py  # スクリプトをスタブ環境で実際にロードして検証
```

| パス | 役割 |
|---|---|
| `tools/mcmodel.py` | ジオメトリビルダー（ボックスUVの自動パッキング付き） |
| `tools/mctexture.py` | UV矩形に沿ってテクスチャを描くプロシージャルペインタ |
| `tools/palettes.py` | 各エンティティの配色 |
| `tools/gen_entities.py` | 全エンティティのモデルとテクスチャ |
| `tools/gen_client_entities.py` | リソースパックのエンティティ定義・アタッチャブル |
| `tools/gen_items.py` | アイテムアイコン・防具レイヤー・パックアイコン |
| `tools/gen_bp.py` | アイテム・エンティティ・湧き条件・ルート・レシピ |
| `tools/gen_lang.py` | ja_JP / en_US 言語ファイル |
| `packs/kaiju8_BP/scripts/` | ゲームロジック（変身・解放戦力・要塞度・怪獣災害） |
