# 基盤の実物レビュー（着手前の所見）

`tools/marvel/preview.py` で実際にレンダリングして確認した、**現状の具体的な欠点**。
制作担当は自分の担当分をここから潰していくこと。

レンダリングの仕方:

```bash
python3 tools/marvel/preview.py magneto              # 前後 2 面
python3 tools/marvel/preview.py --all                # 全キャラ
python3 tools/marvel/preview.py --props              # 技の実体
python3 tools/marvel/preview.py --pose tech.repulse magneto   # 技の姿勢で
```

出力は `scratchpad/marvel_preview.png`。**Read ツールで画像を開いて自分の目で見ること。**
見ずに「直した」と言わない。

---

## 全体に効いている問題

### 1. 全部が暗すぎる／コントラストが無い
センチネル・ミスティーク・ジャガーノートが、いずれも「黒っぽい塊」に見える。
原因は複合的:

- `colours.py` の `_common()` が置く既定色の明度が低い
- `mctexture.Painter.paint_face()` の `ao`（既定 0.30）が面の縁を大きく落とす
- `FACE_LIGHT` で down 面が 0.64 倍、east 面が 0.84 倍になる
- そこへ `shade()` の重ねがけが乗る

結果、素材が違っても画面上ではどれも同じ暗さになる。
**素材ごとの明度差を、暗い側ではなく明るい側で作ること。**
金属は `#8A9099` 前後ではなく `#B4BCC6` 前後まで上げてよい。
布と金属で最低でも 40% は明度差をつける。

### 2. シルエットが全員同じ
体格パラメータ（cm / heads / sh / limb / bulk）は効いているが、
**衣装がどれも「胴体に箱をかぶせただけ」** なので、遠景で区別がつかない。
それぞれに「その人にしか無い外形」を一つずつ足すこと。
（例: セイバートゥースの鬣、トードの猫背と長い腕、ブロブの腹、
　センチネルの頭頂フィン、ジャガーノートのドーム兜）

## キャラ別

### マグニートー（担当 1）
- **マントが幅広すぎて「赤い壁」に見える。** 現在 `shoulder_w * 1.10` から
  最下段で `* 1.32` まで広がり、長さが `total * 0.62`。正面から見ると
  胴体がほぼ隠れる。肩幅程度から始めて、裾で 1.15 倍程度に留めるべき。
  長さも `0.48` 前後まで詰める。
- **マントに襟が無い。** 首の後ろに立ち上がる襟を足すと、一気にマグニートーになる。
- **兜のフィンがフィンに見えない。** 現在は前面に薄い箱を一枚置いているだけなので、
  正面から見ると平らな板。`rotation` を使って左右へ跳ね上げた
  独立した二枚として作り直す必要がある。
- 頬当てと露出した顔の境界が曖昧。顔の cube が兜に埋もれている。
- 胸の紋章 `mag_sigil` が小さすぎて、遠景で見えない。
- 肩のパウルドロンが胴と一体化して見える。段差か色差が要る。

### ブラザーフッド（担当 2）
- ミスティークの青が沈んでいる。鱗の表現が模様として読めない。
  髪の赤が暗くて黒に見える。
- ジャガーノートのドーム兜が、ただの箱。顔が完全に隠れる巨大な兜なので、
  ここは思い切って大きく・丸く作ってよい。
- トードの猫背 (`hunch=14`) が効いているか要確認。腕をもっと長くしてよい。
- ブロブの腹の張り出しが足りない。`bulk=2.10` の割に細く見える。
- クイックシルバー・パイロ・アバランチが互いに似すぎている。

### 敵（担当 3）
- **センチネルが小さく見える。** cm=440 なのに、遠景で人間と同じ形。
  頭を大きく、肩幅をさらに広げ、頭頂のフィンを伸ばすこと。
- オプティックバー（目の横一文字）が暗くて光って見えない。
  発光は `EM` アルファで指定しているが、下地が暗いと効果が弱い。
- プライム・センチネルが Mk-I と見分けがつかない。
- 技の実体（`--props` で確認）は未検証。特に `barrier_dome` `ruin_sphere`
  `iron_cage` は「大きく見せる」ことが目的なので、実際に見て判断すること。

## 動きについて（担当 5・6）

- 技のキーは書けているが、**実機で確認できていない**。
  `--pose tech.<名前>` で静止画としては確認できるので、
  少なくとも「撃発の瞬間の絵」が決まっているかは目で見て確かめること。
- `gen_anim_loco.py` の `form.*` は変身体に重ねる味付けだが、
  プレイヤー本体のアニメーションと二重にならないか要検討。
- 一人称の `fp_hand` は、実際に手前に出たときの大きさが未検証。
  大きすぎると画面が埋まる。

## 演出について（担当 7）

- パーティクルは 81 種あるが、**多くが「点を撒く」だけ** で
  技ごとの個性が薄い。層の重ね方で差をつけること。
- `mag_field` `mag_glyph` など、`glyph` セルを使う効果は
  実際に画面に出たとき何に見えるか未検証。

## 遊びについて（担当 8・9）

- 磁力でブロックを引き剥がす処理 (`ripBlock`) はあるが、
  **引き剥がしたブロックが戻らない**（世界が穴だらけになる）。
  これは実際に遊ぶと問題になる。設置し直すか、範囲を絞るか、判断が要る。
- `scanMetal` は半径が大きいと重い。`step` で間引いてはいるが、
  必殺技の半径 40 は実測していない。
- 技の威力・コスト・クールダウンは机上の値。役割の重なりを点検すること。
